# Estilos (escolha pelo nome)

## Legendas

A palavra que está sendo falada sempre muda pra cor de destaque.

| Nome | Como fica |
|---|---|
| **Impacto** | Letra alta e estreita (Anton), caixa alta, contorno preto, 1 a 3 palavras |
| **Caixa na palavra** | Uma caixa colorida atrás da palavra falada, texto escuro dentro dela |
| **Palavra gigante** | Uma palavra por vez, bem grande, com sombra colorida |
| **Pulso** | A palavra falada fica 25% maior e colorida |
| **Fita** | Texto branco numa faixa preta inclinada, alinhada à esquerda |
| **Papelaria** | Contorno escuro grosso, a frase vai se escrevendo palavra por palavra |
| **Discreta** | Letra mais fina, frase em até 2 linhas sobre faixa escura, sem animação |

## Ganchos (texto dos primeiros segundos, no alto da tela)

| Nome | Como fica |
|---|---|
| **Manchete** | Caixa alta grande, contorno preto, a segunda linha na cor de destaque |
| **Tarjas** | Cada linha numa tarja sólida, uma branca e outra colorida, levemente inclinadas |
| **Balão** | Balão branco de conversa, como uma pergunta do público |
| **Marca-texto** | Texto escuro sobre faixas de marca-texto coloridas |
| **Vidro escuro** | Painel escuro translúcido, texto branco e um traço colorido |

## Cor de destaque

Diga o nome ("amarelo", "rosa", "rosa claro", "nude", "champagne", "dourado", "lilás", "azul bebê", "verde limão", "terracota", "vinho"...) ou o código (#FFC400). Padrão: amarelo.

## Animações

Poucas (uma a cada 10 a 15 s), médias (uma a cada 5 a 8 s) ou nenhuma.
